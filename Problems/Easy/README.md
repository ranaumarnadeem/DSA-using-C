# Easy Problems

Collection of easy-level DSA problems with solutions.

## Problems

1. **Reverse an Array** (`reverse_array.c`)
   - Given an array, reverse it in-place
   - Time: O(n), Space: O(1)

2. **Find Maximum in Array** (`find_max.c`)
   - Find the largest element in an array
   - Time: O(n), Space: O(1)

3. **Check Palindrome** (`check_palindrome.c`)
   - Check if a string is a palindrome
   - Time: O(n), Space: O(1)

## How to Use

Each file contains:
- Problem description
- Solution approach
- Complete working code
- Test cases

Compile and run:
```bash
gcc reverse_array.c -o reverse_array
./reverse_array
```
