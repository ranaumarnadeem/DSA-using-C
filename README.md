# DSA using C

A comprehensive repository for practicing Data Structures and Algorithms in C. This repository is particularly useful for embedded engineers and anyone looking to strengthen their understanding of DSA concepts using C programming.

## 🎯 Purpose

This repository aims to:
- Provide clean, well-documented implementations of common data structures in C
- Offer practical algorithm implementations with explanations
- Include practice problems with detailed solutions
- Help embedded engineers and C programmers improve their DSA skills
- Serve as a quick reference for interviews and competitive programming

## 🚀 Getting Started

### Prerequisites
- GCC compiler or any C compiler
- Make (optional, for using Makefiles)
- Basic understanding of C programming

### Compilation

Each directory contains its own examples. To compile a specific program:

```bash
gcc -o output_file source_file.c
./output_file
```

Or use the provided Makefile:

```bash
make
```

## 📖 How to Use This Repository

1. **Learning Data Structures**: Navigate to the `DataStructures/` directory and explore implementations with examples
2. **Practicing Algorithms**: Check the `Algorithms/` directory for various algorithm implementations
3. **Solving Problems**: Work through problems in the `Problems/` directory, organized by difficulty level

## 🎓 Topics Covered

### Data Structures
- Arrays and Dynamic Arrays
- Singly and Doubly Linked Lists
- Stacks (Array and Linked List based)
- Queues (Simple, Circular, Priority)
- Binary Trees, BST, AVL Trees
- Graphs (Adjacency Matrix, Adjacency List)
- Hash Tables with collision handling

### Algorithms
- Sorting: Bubble, Selection, Insertion, Merge, Quick, Heap Sort
- Searching: Linear, Binary, Interpolation Search
- Dynamic Programming: Fibonacci, Knapsack, LCS, etc.
- Greedy Algorithms: Activity Selection, Huffman Coding
- Graph Algorithms: BFS, DFS, Dijkstra, Kruskal, Prim
